# Karily Thread And Needle

Crea una aplicación web moderna y responsiva en React y Tailwind CSS para un negocio real llamado "Karily", ubicado en Degollado #120 A, Zapotlanejo, Jalisco, México.

Descripción del negocio: Taller especializado en bordados personalizados e industriales para todo tipo de prendas de ropa. Contamos con bordadoras profesionales para crear diseños a la medida del cliente con alta precisión y calidad.

Secciones requeridas:

Inicio (Hero): Título llamativo, subtítulo atractivo sobre bordados personalizados y un botón que lleve al formulario de cotización.

Servicios: Tarjetas visuales para los 3 servicios principales: Bordados personalizados, Creación y digitalización de diseños y Elaboración de muestras.

Galería: Una sección con 3 o 4 imágenes de ejemplo de prendas bordadas (fáciles de reemplazar después).

Ubicación: Mostrar la dirección (Degollado #120 A, Zapotlanejo, Jalisco, México) y un botón que abra la ubicación en Google Maps.

Formulario de cotización funcional: Campos para Nombre, Correo/WhatsApp, Tipo de servicio (lista desplegable), Cantidad de prendas y Descripción del diseño. Al enviarlo, debe validar los campos y mostrar un mensaje de confirmación en pantalla con el resumen de los datos enviados.

Pie de página (Footer): Debe incluir un espacio reservado para el logo de CUCEI y los siguientes textos: Nombre del alumno: [Cesar Emanuel Hernandez Perez], Materia: [Desarrollo de Aplicaciones Web y Móviles], Profesor: [Zeus Emanuel Guitierrez Cobian], Calendario: [2026-B].

Diseño: Usa una paleta de colores elegante y artesanal (por ejemplo, tonos crema, azul marino o vino, y detalles en dorado/mostaza). Asegúrate de que se vea excelente tanto en computadora como en celular.
